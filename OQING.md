# Olimjon Isxakov darsligi

Saytni Vercel'ga joylash:

1. Shu papkadagi hamma faylni GitHub'ga yuklang (`api` papkasi bilan).
2. Vercel: Add New > Project > shu repo > Framework Preset: Other > Deploy.
3. Settings > Environment Variables:
   - `BOT_TOKEN` - BotFather bergan token
   - `CHAT_ID` - botga Start bosgan odamning raqami (bir nechta bo'lsa vergul bilan)
4. Deployments > Redeploy.
5. Saytda sinov raqami qoldiring, botga xabar kelishi kerak.

Tokenni GitHub'ga yozmang.

Matnni o'zgartirish: `manba.html` ni tahrirlang, keyin `python3 yig.py` - `index.html` yangilanadi.
